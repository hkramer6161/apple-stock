02 — How it works

Three steps, on a loop.

1

Opens the product page

A hidden Chrome loads the real store page and reads every model: part number, colour, storage, price. The UI builds itself from that list.

2

Asks the stock API

The same endpoint the store uses, called from inside the real page, so it isn't turned away with a 541 like a bare script.

3

Compares with last time

State lives in .state.json. Only a change from unavailable to available fires an alert, so your phone stays quiet until it matters.
